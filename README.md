# KeyPassGen

Press keys and get a strong code.<br>

## Using

Follow tips.<br>

## Compile

Please switch compilers. For developers who don't have clang, you can switch to other compilers.<br>
And then make sure you use [GNU/make](https://www.gnu.org/software/make/).<br>
Once all the previous steps are complete, please run the command: `make -k`.<br>
